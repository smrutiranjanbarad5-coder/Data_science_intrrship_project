# Convert numerical columns to numbers

df['mileage'] = pd.to_numeric(
    df['mileage'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)

df['engine'] = pd.to_numeric(
    df['engine'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)

df['max_power'] = pd.to_numeric(
    df['max_power'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)

df['torque'] = pd.to_numeric(
    df['torque'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)

df['seats'] = pd.to_numeric(df['seats'], errors='coerce')

# Fill missing values with median
for column in ['mileage', 'engine', 'max_power', 'torque', 'seats']:
    df[column] = df[column].fillna(df[column].median())

# Check missing values
print("Missing values after cleaning:")
print(df.isnull().sum())

Used Cars Cost Prediction¶

Project Conclusion¶

This project predicts the selling price of used cars using Machine Learning.

Dataset¶

The dataset contains information about used cars such as:

  • Year
  • Kilometers Driven
  • Fuel Type
  • Seller Type
  • Transmission
  • Owner
  • Mileage
  • Engine
  • Max Power
  • Torque
  • Seats

Data Preprocessing¶

  • Missing values were identified.
  • Numerical values were cleaned and converted into numeric format.
  • Missing numerical values were replaced using the median.
  • Categorical features were converted into numerical values using One-Hot Encoding.

Machine Learning Model¶

Linear Regression was used to predict the selling price of used cars.

Model Evaluation¶

  • MAE: 269473.67
  • RMSE: 453338.45
  • R² Score: 0.6865

The model achieved an R² score of approximately 68.65%.

Conclusion¶

The project demonstrates how Machine Learning can be used to estimate the selling price of used cars based on their features.
